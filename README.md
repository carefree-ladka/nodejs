# Node.js + Express Academy

A documentation site built with [Docusaurus](https://docusaurus.io/) that teaches **Node.js and Express from JavaScript basics to a production deployment**.

The curriculum is organized into ten ordered phases, each with concepts, explanations, and a hands-on mini-project. The mini-projects chain into one real REST API that you structure, add a database to, secure, test, containerize, and deploy.

## Curriculum

| Phase | Topic                      |
| ----: | -------------------------- |
|     0 | JavaScript Foundations     |
|     1 | Node.js Fundamentals       |
|     2 | HTTP & Web Fundamentals    |
|     3 | Express Fundamentals       |
|     4 | Structure & Best Practices |
|     5 | Databases (SQL & NoSQL)    |
|     6 | Authentication & Security  |
|     7 | Testing                    |
|     8 | Advanced Topics            |
|     9 | DevOps & Deployment        |

Content lives in `docs/`, one folder per phase.

## Local development

```bash
npm install
npm start
```

This starts a local dev server at `http://localhost:3000` with hot reload.

## Build

```bash
npm run build
```

Generates static content into the `build/` directory, servable by any static host.

```bash
npm run serve
```

Serves the production build locally to preview it.

## Project layout

```
docs/                 # the curriculum (one folder per phase)
src/pages/index.tsx   # landing page
src/components/        # homepage feature components
docusaurus.config.ts  # site config (title, navbar, footer)
sidebars.ts           # sidebar (autogenerated from docs/)
```

## Deploying this site

The `build/` output is plain static files. Host it on Netlify, Vercel, GitHub Pages, Render, Cloudflare Pages, or any static host. See the Docusaurus [deployment docs](https://docusaurus.io/docs/deployment).
