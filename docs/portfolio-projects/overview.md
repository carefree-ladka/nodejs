# Portfolio Projects

Tutorials prove you can follow along. **Projects prove you can build.** These four, in order, show a complete arc from fundamentals to a production AI system. Build them as you progress through the phases — each one exercises the skills from the phases before it.

## What "done" means for every project

For each project, don't stop at "it runs locally." Ship it like a professional:

- ✅ **Source code** on GitHub, clean commit history, no secrets committed.
- ✅ **A useful README** — what it does, how to run it, tech choices and why.
- ✅ **API documentation** — OpenAPI/Swagger (Phase 3 / Phase 8).
- ✅ **Automated tests** — unit + integration (Phase 7), running in CI.
- ✅ **A deployed demo** — a live URL (Phase 10).
- ✅ **An architecture diagram** — boxes and arrows showing the moving parts.

That checklist is what turns "I did a course" into "here's what I built."

## The four projects

| # | Project | Level | Headline skills |
|---|---------|-------|-----------------|
| 1 | [Task Manager API](./project-1-task-manager) | Beginner | CRUD, TypeScript, PostgreSQL, auth, validation, tests, docs |
| 2 | [Production E-commerce Backend](./project-2-ecommerce) | Intermediate | Redis caching, background jobs, payments (sandbox), Docker, CI/CD |
| 3 | [AI Knowledge Assistant](./project-3-ai-knowledge-assistant) | AI intermediate | RAG, pgvector, streaming, citations, per-user access control |

Start at #1 even if AI is your goal — projects 3 and 4 assume the backend fundamentals that 1 and 2 build.
