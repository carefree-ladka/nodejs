# Node.js + Express Academy

Welcome. This is a complete, ordered path from **JavaScript fundamentals** all the way to a **deployed, production-grade Express API**. It is opinionated on purpose — the goal is to get you building real backends without getting lost.

## How the course is structured

The curriculum is split into **ten phases**. Each phase builds on the one before it, so resist the urge to skip ahead.

| Phase | Focus                                            |
| ----: | ------------------------------------------------ |
|     0 | JavaScript foundations (the prerequisite)        |
|     1 | Node.js fundamentals, internals & the event loop |
|     2 | HTTP & web fundamentals                          |
|     3 | Express fundamentals (+ TypeScript & Fastify)    |
|     4 | Project structure & best practices               |
|     5 | Databases (SQL & NoSQL)                          |
|     6 | Authentication & security                        |
|     7 | Testing                                          |
|     8 | Advanced topics                                  |
|     9 | Generative AI engineering                        |
|    10 | DevOps & deployment                              |

Plus a [**Portfolio Projects**](/portfolio-projects/overview) track — four projects, from a typed CRUD API to a production AI agent — to prove what you've learned.

Each phase has:

- **What to learn** — the concepts, in order.
- **Why it matters** — so you understand the point, not just the syntax.
- **A mini-project** — because reading alone doesn't stick.

The mini-projects chain together: by Phase 9 you will have taken a single REST API from an in-memory toy to a containerized, tested, deployed service.

## How to use this site

1. Go through phases in order. Each page has next/previous navigation at the bottom.
2. **Type the code yourself.** Don't copy-paste. Muscle memory matters.
3. Build every mini-project before moving on.
4. Keep the [Node.js](https://nodejs.org/en/docs) and [Express](https://expressjs.com/) docs open in a tab.

## What you need installed

- **Node.js LTS** (check with `node --version`)
- A code editor (VS Code is a great default)
- A terminal you're comfortable with
- Git

:::tip
Use the latest **LTS** (Long Term Support) release of Node for learning. Odd-numbered major versions are not LTS.
:::

## Guiding principles

1. **Build, don't just read.** Every phase has a project for a reason.
2. **One concept at a time.** Don't jump to auth before routing is solid.
3. **Read error messages carefully** — they usually tell you exactly what's wrong.
4. **Ship something small early.** Deploy a trivial app in week two so deployment isn't scary later.
5. **Security and error handling aren't "advanced."** Bake them in from Phase 4.
6. **Learn backend engineering first, then add AI.** The AI phase builds directly on everything before it — an AI feature still needs auth, storage, validation, and tests.
